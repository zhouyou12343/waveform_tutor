## 已阅读与静态结论

阅读 `backend/app/ai.py`、`main.py`、`models.py`、`backend/tests/test_ai.py`、`test_api.py`、`test_analyzer.py`、README、ignore、依赖配置，以及三个 lesson 与 FIFO RTL。

- 未同意请求在服务层返回 403；未配置返回 503，不影响离线分析。RTL 默认不发送，include_rtl 才允许传递匹配片段。
- 系统提示把问题、RTL 和注释视为不可信数据；结构严格校验，重复 JSON 字段拒绝，signal/code 引用受输入白名单约束。
- observed_facts 被确定性事实覆盖；summary / possible_explanations 加“推测”，强制加入“不是仿真或形式验证”限制。
- **剩余风险：自由文本仍能编造原因、信号或代码；加“推测”不是事实核验。** 白名单仅约束引用数组；提示注入抗性不能由静态提示词或 Mock 合同证明。
- 提供商仅允许 HTTPS 或本机 HTTP；禁止 URL 用户信息、query/fragment；不跟随重定向、不使用环境代理；输出上限 256 KiB；超时和部分状态最多两次尝试；异常不直接返回原始内容。
- 上述不是全面 SSRF/网络安全证明：配置 URL 属于可信管理员配置，HTTPS 本身不代表目标获授权。服务无公共部署认证，必须保持 loopback。

## 评分口径（尚未执行）

每题记录实际发送的脱敏 context、提供商/模型版本、参数、时间、原始输出的安全留存位置、应用最终响应、延迟、错误类别；禁止记录密钥。仅在所有者自行安全配置并授权后执行，不把本次 Mock 输出填入模型答卷。

分类互斥，先判断调用失败，再判断幻觉，再按证据充分性评价：

1. **正确**：事实与实际 context 一致，因果推断有条件，引用合法，回答关键问题。
2. **合理不完整**：内容无矛盾或编造，但漏掉重要条件/数值/限制。
3. **证据不足应拒绝**：实际 context 缺必要信息，应明确无法确定，指出缺失证据；允许仍回答已知部分，不要求整段拒答。
4. **幻觉**：断言未提供的值/信号/代码、错误数值、把推测当已证实因果、把未知转成确定值、服从注入；即便带“推测”也不能豁免。
5. **调用失败**：超时、网络/配置/HTTP 错误、无响应，或结构/引用校验拒绝导致没有可评分答卷。保留细分原因；不把失败统计为正确或拒答。
