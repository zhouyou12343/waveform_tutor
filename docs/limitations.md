# 已知限制与解释边界

本项目服务于本科教学中的小规模数字波形阅读。本机测量见 [QA 性能报告](qa/performance-report.md)，不提供工业规模适用性或形式正确性保证。

## 格式和资源限额

| 资源 | 当前上限/范围 |
| --- | --- |
| VCD 文件 | 8 MiB |
| 信号声明 | 512，别名也计为信号 |
| 信号位宽 | 1–256 bit |
| 事件 | 别名展开后最多 100,000 条；原始文件记录数不等于展开后数量 |
| scope 嵌套 | 最多 32 层 |
| 名称 | scope/ref/id_code 各最多 256 字符；完整信号名 1024 字符；累计 name+scope 128 Ki 字符 |
| 时间 | 非负、单调不减整数 tick；最大 `2^53 - 1`；允许同时间戳 |
| RTL 文件 | UTF-8 `.v`/`.sv`，每个最多 128 KiB；拒绝空白或含 NUL 文本 |
| 每 trace 源码 | 最多 8 个，包含自带案例的 design/tb；不允许同名 |
| 内存 trace | 最近加载的 4 个，淘汰最旧；非持久化 |
| 请求所选/可见信号 | 最多 16 个 |
| 图形渲染 | 每信号每窗口最多 2,000 segments，截断会提示 |
| 分析窗口事件 | 每信号最多前 128 条，`truncated` 标记 |
| 源码匹配 | 最多 32 项，每项行文本最多 300 字符 |
| AI 响应 | 最多 256 KiB；默认输出 token 上限 2048 |

支持数字 VCD 标量/向量及 0/1/X/Z、层级名称、标识符别名和 timescale（s/ms/us/ns/ps/fs）。接受的数字声明类型包括 wire、reg、integer、parameter、supply0/1、time、tri 系列、wand、wor。不是对所有 VCD 扩展的支持承诺。

不支持 FST/FSDB、real/string/event 信号、VCD 属性扩展或完整 SystemVerilog AST。非法、缺失声明、无法匹配位宽或超限文件会被拒绝，不应靠静默丢弃数据伪装成功。

## 时间、值与波形

- 时间单位是 trace 声明的 tick，而非固定 ns。示例为 1 ps/tick，120000 tick 才是 120 ns。
- 光标值取该时间戳最后一条记录。窗口可保留同时间戳多条记录，但 SVG 中零持续时间变化可能不形成可见段。
- previous/next 指严格早于/晚于光标的记录，不是“同一 tick 内的前后 delta-cycle”。
- VCD 文件顺序不等于完整 RTL 执行语义，不能证明 delta-cycle、NBA 调度、驱动链或因果。
- 只检测确定的 0→1/1→0；X/Z 过渡不计为确定边沿。边沿邻近性不能证明数据满足 setup/hold。
- 没有记录时是未知的“尚无记录”，不应替换成 0。含 X/Z 的总线保持二进制；十进制是无符号解释，不推断 signed 类型。
- 含 `$dumpoff` 的文件整体拒绝：尚未建模停录区间，不能把旧值沿用为确定事实。`$dumpvars`、`$dumpall`、`$dumpon` 仍可解析。
- 渲染和窗口事件有不同上限。缩小窗口查看遗漏内容；空白或截断不表示没有事件。没有大波形流式索引、懒加载或完整调度可视化。

## 源码和案例

RTL 每页最多显示 200 行；搜索跨全文，保留源文件行号。名称匹配采用 ASCII 标识符边界，CR/LF/CRLF 等分行在前后端一致；仍不支持带 `.` 的转义标识符的完整层级语义。

源码关联仅按叶信号名文本匹配，可命中注释、不同模块中的同名变量，也可能漏掉复杂标识符。它不证明该行驱动此信号，不解析宏、generate、完整 AST 或数据流。

时钟、复位极性和同步/异步模式由用户配置；模式不是从波形推断出的事实。示例 testbench 的断言只覆盖各自案例，不证明任意上传设计正确。FIFO 的满/空同时读写规则具有案例特定性，不能直接推广到所有 FIFO。

程序不执行上传的 RTL。`scripts/generate_examples.py` 仅调用固定可信仓库示例；其临时目录不是恶意代码安全沙箱。

## 数据生命周期与部署

没有数据库、保存项目、恢复会话或用户隔离。应用不持久保存上传文件，后端 trace 存于进程内存；底层 multipart 实现可能使用临时缓冲/临时文件，不能保证操作系统层面无任何磁盘痕迹。浏览器下载的报告由用户自行管理。

最多四个 trace，重启和容量淘汰会丢失，前端刷新不自动恢复工作区。多个 worker 不共享这份内存。建议单进程、loopback 启动，设置并发上限。主机/Origin 检查不等于身份认证；不适合直接公开、多租户或处理恶意客户端的互联网服务。

## AI 的可信度与隐私

AI可通过网页保存到本机后端配置，也可由环境配置；每次请求仍需明确同意，RTL片段另行授权。网页配置保存在Git忽略的.waveform-tutor目录，是明文且无多用户隔离，不能作为公网服务直接开放。保存不验证密钥/模型是否有效，不自动发送数据；保存或重启会重置实例计数。网页配置增量按用户要求未执行新的运行验证。发送的信号名、问题和事件也可能是敏感数据。第三方服务可能有自己的保留、计费和使用条款；取消请求不保证远端停止或删除数据。

结构校验、引用白名单和后端覆盖 `observed_facts` 只能约束部分输出。summary、possible_explanations、suggested_checks 等自由文本仍可能编造、误导或受提示注入影响。不能将模型文字当作新的波形事实、已证实因果或形式验证结论。

支持显式选择的非流式 OpenAI-compatible Chat Completions 与 Responses 请求形状，不保证任意提供商、模型或 JSON 行为兼容。`AI_API_FORMAT` 默认 chat_completions，可设 responses，不自动回退其他端点。Responses要求完整assistant文本，不支持SSE、工具执行、会话延续或后台轮询；store=false仅为请求参数，不保证第三方无留存。max_output_tokens可能同时计入推理与可见输出。默认单次 HTTP 超时 30 秒，`AI_MAX_ATTEMPTS` 默认 2、可设 1；总截止是配置超时 × 尝试次数 + 0.1 秒。网络重试可能重复计费；可设置 `AI_REQUEST_BUDGET` 对本进程 HTTP 尝试设上限，包含失败和取消，重启会重置，不是持久授权或账本。后端在分析完成后复查客户端断开，但无法保证网络通知即时到达或撤回已发送数据。只有 loopback 提供商允许 HTTP，远程必须 HTTPS。Mock 测试不验证实际提供商质量。无 AI 时核心分析仍可离线使用。

分析窗口不保证等于可见视口；上下文还包含可能位于窗口外的相邻记录，以及独立配置的 clock/reset。名称匹配的 32 项/300 字符片段可能漏掉敏感列表、条件和采样逻辑。本轮准备器明确记录 C3、F2、H1/H3 等必要 RTL 的缺失，评分只能依据实际 context，不能让模型猜评审侧完整代码。
